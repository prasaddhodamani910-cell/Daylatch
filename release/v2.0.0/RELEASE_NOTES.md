# Daylatch 2.0.0 release

- Completion is locked to the current Daylatch date; past and future cells are read-only.
- Insights includes monthly score, trend graph, completion split, and habit leaderboard.
- Offline-first: no INTERNET permission.

- Included APKs: `Daylatch-v2.0.0-debug.apk` (installable) and `Daylatch-v2.0.0-release-unsigned.apk` (for final store signing).
- Debug and unsigned release APKs were verified by successful Gradle builds on this device.
Build: `gradle assembleDebug`
